## Дистрибуция

Поддерживайте дистрибуцию простой, без обязательной установки. Используйте только Rust и поставляйте самодостаточные бинарники.

## Перед отправкой

Запустите объединённую проверку (форматирование, линтер, тесты):

```bash
cd scripts && cargo run -- check
```

Или выполните шаги по отдельности: `cargo fmt --all -- --check` (чисто), `cargo clippy --workspace --all-targets -- -D warnings` (0 предупреждений), `cargo test --workspace`.

Так как тесты прогоняют релизные сценарии в одноразовых Git-репозиториях, Git должен быть установлен.

## Вопросы и ответы

### Почему нет шелл-скриптов и мейк-файлов?

Всё написано на Rust, включая скрипты. Введение другого языка добавляет платформенную зависимость и сложность. Cargo портативен и надёжен.

Сборка выполняется командой:

```bash
cd scripts && cargo run -- build
```

Инкрементальная компиляция cargo делает повторные сборки быстрыми. Мейкфайлы не нужны.

Артефакты для четырёх публикуемых платформ собираются, когда установлены их тулчейны (`rustup target add x86_64-apple-darwin` и т.п.); `build` пропускает отсутствующие таргеты с подсказкой.

### Можно ли использовать библиотеку X?

Нет, с одним исключением: единственная JSON-зависимость (`serde_json`), на которой построено обновление `package.json`. Во всём остальном используется только стандартная библиотека Rust.
